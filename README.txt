MYDAY - PROTOTIPO INIZIALE

Questa è una prima bozza funzionante dell'interfaccia MyDay.

FUNZIONA GIÀ:
- attività da fare e completamento
- routine e abitudini
- note personali con salvataggio automatico
- registrazione locale delle spese
- obiettivi mensili
- statistiche di base
- tema chiaro/scuro
- cache offline (dopo la prima apertura, se servita da HTTPS)

IMPORTANTE:
Questa versione salva i dati solo nel browser/dispositivo corrente.
Non include ancora account, accesso Google/Apple, sincronizzazione cloud,
notifiche programmate né backup tra dispositivi. Queste funzioni richiedono
un backend, configurazione e test dedicati.

COME PROVARLA:
1. Estrai la cartella.
2. Pubblica i file su un hosting statico HTTPS (per esempio un servizio
   di hosting per siti statici) oppure esegui un server locale.
3. Apri l'indirizzo dal browser del telefono.
4. Usa "Aggiungi alla schermata Home" dal menu di condivisione/browser.

È un prototipo web installabile (PWA), non ancora un'app nativa negli store.
